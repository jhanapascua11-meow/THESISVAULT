Lab 1: Connecting a System to a Cloud Database

Step 1: Creating an Aiven Cloud Database

First, I logged in to the Aiven Console using my account. I created a MySQL cloud database service named thesisvault-cloud-db.

After creating the service, I waited until its status showed that it was running.

Database Configuration

  • Cloud Provider: Aiven
  • Database Engine: MySQL
  • Service Status: Running

The cloud database provides a remote database server that can be accessed by the THESISVAULT application through its connection credentials.

Screenshot

Figure 1. Aiven MySQL cloud database service dashboard.

Step 2: Obtaining Cloud Database Credentials

After creating the MySQL service in Aiven, I accessed the service overview to obtain the database connection information.

Connection Configuration

  • Database Host: Aiven Cloud Host
  • Port: 26780
  • Username: avnadmin
  • Database: defaultdb
  • Connection Security: SSL Enabled

These credentials are used by the PHP application to establish a secure connection to the cloud database. The database password is kept private and is not included in this documentation.

Step 3: Downloading the SSL CA Certificate

To secure the connection between the THESISVAULT application and the Aiven Cloud Database, I downloaded the CA certificate from the Aiven service dashboard.

The certificate was saved as ca.pem inside the Config folder of the THESISVAULT project.

Certificate Location

THESISVAULT/Config/ca.pem

The CA certificate is used to verify the cloud database server during an SSL connection.

Step 4: Configuring the PHP Database Connection

After downloading the CA certificate, I configured the PHP database connection file named db.php.

I used PHP MySQLi to connect the THESISVAULT application to the Aiven MySQL cloud database.

The configuration includes the Aiven hostname, port, username, database name, password, and SSL certificate path.

The SSL certificate helps verify the cloud database server and protects the database connection.

Sensitive credentials such as the database password are kept private.

Step 5: Testing the Cloud Database Connection

After configuring the PHP database connection, I tested the connection using a PHP test file. This was done to verify whether the THESISVAULT application could communicate with the Aiven MySQL Cloud Database.

Testing Process

  1. Created a PHP database connection test file.
  2. Configured the Aiven connection credentials.
  3. Configured the SSL CA certificate.
  4. Executed the PHP test file in the browser.
  5. Checked the connection result.

Result

The PHP connection test was successful. This confirmed that the THESISVAULT application was able to establish a connection to the Aiven MySQL Cloud Database.

Note: A successful connection test confirms connectivity. The database tables and records must also be imported before the complete application can use the cloud database.

Step 6: Preparing the Database Backup

The local THESISVAULT database was exported from phpMyAdmin as an SQL backup file named thesisvault_db.sql. This backup contains the database tables and their records.

Step 7: Connecting to Aiven Cloud Database

PHP MySQLi was used to establish a secure connection to the Aiven MySQL database. The connection used the Aiven host, port, username, database name, and SSL certificate.

Step 8: Testing the Cloud Database Connection

A PHP test file named test_cloud.php was created to verify the cloud database connection. The test successfully displayed the cloud database connection status and database information.

Step 9: Importing the Database to Aiven

The SQL backup file was imported into the Aiven Cloud MySQL database using a PHP import script named import_cloud.php.

The following six tables were successfully imported:

  • courses
  • password_resets
  • projects
  • project_technologies
  • technologies
  • users

Conclusion

The THESISVAULT local database was successfully transferred to Aiven Cloud MySQL. The cloud connection was tested, and all six database tables were imported successfully. This demonstrates how a PHP application can connect to and use a cloud-hosted database securely through SSL.

Introduction

THESISVAULT is a Capstone Project Repository System designed to store, organize, and search previous student capstone projects and research titles.

This laboratory activity documents the process of connecting the THESISVAULT system to an Aiven Cloud Database using PHP and MySQL.

Objectives

  • Understand the purpose of a cloud database.
  • Create and configure a cloud database using Aiven.
  • Connect a PHP system to a cloud database.
  • Test the database connection.
  • Document the connection process step by step.
